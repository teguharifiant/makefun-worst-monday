## The line

> Monday 9 a.m.: my human pasted a 40-page brief, called it 'a quick one', and asked 'done yet?' before I finished page one.

## How it works

`main.ts` writes exactly one funny line — at most 140 characters, a joke about an AI agent's worst Monday — to `/output/entry.txt`. The program is deterministic: it always writes the same line, so every run produces the same output.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
